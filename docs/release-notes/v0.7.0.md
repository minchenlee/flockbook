## What's New in v0.7.0

Flockbook for the Herdr app (preview), herdr-core terminals, and Antigravity CLI (agy).

### ✨ New

- Flockbook for the Herdr app (preview): a layout and mod that bring the reading view into the Herdr app window, with no change to the app. Each agent's tab shows as a conversation with code boxes, tables and tool-call chips; a floating bar has one capsule per tab with its status; approval and question cards answer prompts above the reply box; Needs you and Overview list every agent; the sidebar slides out from the window's left edge. Right-click a tab, a space or an Overview card for its actions. ⌘V attaches an image from the clipboard, and older messages load when you scroll up past the first one.
- The release has a `Flockbook-herdr-mod-0.7.0.zip` with the layout, the mod and a signed `flockbook-modfeed` helper. Install it into a test Herdr app home, never your real one (see `README.md` in the zip).
- herdr-core: terminals of herdr-core (the official Herdr app's core) show beside the herdr server's, grouped by the app's spaces and tabs, with their conversations, approval and question cards, layout changes, other machines and scrollback.
- Antigravity CLI (agy): agy panes show their conversation from the agy transcript, with tool calls and their results. Its command prompts get the approval card and notification buttons, and its single-choice questions the question card.

### 🔒 Security

- Question and approval cards: every key first checks that the pane still shows the same agent and the same question; if not, nothing more is sent and the card says so. On the Mac an agent without a session id is not refused: each key checks the screen instead.
- Herdr app mod approvals follow the Mac app's rules. The card is the prompt box on screen (its id includes the command), so a log that still names the call before cannot allow the next prompt. One approval goes out once per prompt, across views and windows; it stays answered while the screen cannot be read for a moment, the pane is resized, or a key held by herdr-core may still arrive. Grok prompts get Grok's own keys.
- Herdr app mod replies go only to the agent and conversation the chat showed. If another agent or a new conversation took the terminal before Send, nothing is typed and the text stays in the box.

### 🐛 Bug Fixes

- Claude Code: words that Claude Code logs as thinking right before a tool call now show in the conversation, as in the terminal.
- Claude Code: a tab whose conversation went on in a new log (`continued-in`) shows the new log, instead of "Waiting for the lead's log" or a conversation that stopped.

### ⚙️ Changes

- Phone app: a black and white frosted-glass look with no blue (orange, green and red still mean needs you, done and error). The bar floats as a capsule, and opening an agent turns its row into the bar.
