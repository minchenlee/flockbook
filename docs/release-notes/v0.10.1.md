## What's New in v0.10.1

Two chat fixes in the Herdr app mod, both from an outside contributor: Codex chats that went empty, and notes from other agents.

> **This release is the Herdr app mod only. There is no new Flockbook for Mac build.**
> All changes below are in Flockbook for the Herdr app. Flockbook for Mac stays at
> [v0.8.0](https://github.com/minchenlee/flockbook/releases/tag/v0.8.0): download it there. An installed Mac app
> keeps working and does not offer an update. To get v0.10.1, install or update the Herdr app mod (see Installation below).

### 🐛 Bug Fixes

- Herdr app mod: a Codex chat stays filled once the agent runs a command under automatic approval review or starts a subagent. Codex writes a session file for each of its subagents in the same folder, and the helper took it for a second conversation and showed none (#4).
- Herdr app mod: a note another agent sends with `hc send` shows as one line, "↳ docs-worker: first line", that opens to the whole note on a click, in the chat and on the Phone page. Before, it was a full message bubble with its `<hc>` tag, or it did not show at all (in Codex chats, and short ones in Claude Code chats) (#5).
