## What's New in v0.8.0

Flockbook for the Herdr app on macOS and Linux, installed in one line, with remote tabs and the phone page from the helper (both preview).

### ✨ New

- Install Flockbook for the Herdr app in one line on macOS or Linux: `curl -fsSL https://github.com/minchenlee/flockbook/releases/latest/download/install.sh | sh`. It downloads the helper for your machine, checks it against the release's `SHA256SUMS`, and stops before it runs anything if a sum does not match. Add `-s -- --dry-run` after `sh` to see the plan first.
- The Herdr app mod runs on Linux (x86_64 and arm64). Its helper, `flockbook-modfeed`, is now written in Rust and ships for macOS (universal) and Linux (static). On Linux the + file dialog is off for now.
- The install is now `flockbook-modfeed install`: the layout, mod, themes and keys are built into the helper, so python3 is no longer needed. It never overwrites your files, merges your keys (a `keys.json` that is a symlink stays one), keeps a record of what it put there so a later install updates only its own files, and runs `herdr-app check`.
- The mod's zip carries the helper for every platform, and the install keeps them in `<herdr-app home>/flockbook/remote/` for your other machines, checked against `SHA256SUMS`. In the zip, `./install.sh` runs this machine's helper (`--dry-run` to see the plan first).
- Herdr app mod, remote tabs (preview): tabs on another machine (`hc machine`) get the chat too. The Rust helper runs on that machine (Linux x86_64/aarch64 or macOS; not Windows yet). Before it puts the helper there, a card shows the machine, the path, the size and the SHA-256, and installs only when you press Install; the tab menu can remove it. Tested on a live machine: the chat feed, install, send and remove. Approve and answer on a remote tab are tested only against a simulated machine so far. The Swift helper still skips these tabs.
- Phone page from the helper (preview): `flockbook-modfeed serve` shows the phone page from the Rust helper on macOS and Linux, without the Mac app. It is off unless you start it, and you reach it through Tailscale Serve (guide: `xplat/flockbook-modfeed/SERVE.md`). Not in this version: pictures, older rows, the agent's queue, image upload and notifications.
- Settings > General > Backend chooses what Flockbook follows: Automatic (default: whichever of the herdr TUI and herdr-core answers, with no warning about the other), herdr-core only, Herdr TUI only, or Both. A new choice applies at once.

### 🔒 Security

- The one-line install checks every helper against the release's `SHA256SUMS` before it runs one; the zip's `install.sh` checks a Linux helper against `remote/SHA256SUMS` before it runs it; and the install checks the helpers for other machines again before it copies them.
- Remote tabs: the helper for another machine comes from `<herdr-app home>/flockbook/remote/`. It is checked against `SHA256SUMS` on this machine and again on the other one, and it is installed only after you press Install on the card that shows its SHA-256.
- `flockbook-modfeed serve` listens on 127.0.0.1 only. Every request must carry the `Tailscale-User-Login` of the one account given with `--user`, so Tailscale Funnel requests (which carry no identity) get 403. Approve, answer and send need a JSON `POST` from the page's own `https://` origin, so another site open in your browser cannot use your identity. `send` goes only to the agent and conversation the page showed. Any user of the machine can reach 127.0.0.1, so do not run `serve` on a machine you share with users you do not trust.

### 🐛 Bug Fixes

- Two presses of Allow at the same moment (two views, or a double key) could each send a key; now only one does.
- When two presses of Allow meet, the one that loses now says "Press again" instead of "already answered", and a run that was killed mid-press no longer blocks the next press.

### ⚙️ Changes

- The README puts Flockbook for the Herdr app first, with screenshots of each part; the Mac app's details moved to `docs/mac-app.md`.
- The Herdr app mod source moved from `herdr-mod/` to `herdr-app/`. The release zip keeps its name (`Flockbook-herdr-mod-<version>.zip`); it now also has `remote/` with the helpers for other machines.
- The Herdr layout gallery (https://herdr.dev/gallery/) lists Flockbook from the new folder: "add this layout: https://github.com/minchenlee/flockbook/tree/main/herdr-app". The old folder link (`tree/main/mod`) no longer exists.
