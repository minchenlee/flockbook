## What's New in v0.9.0

Flockbook settings and update notices in the Herdr app mod, drag to reorder tabs and workspaces, ⌘V for files and pictures, and chat fixes.

> **This release is the Herdr app mod only. There is no new Flockbook for Mac build.**
> All changes below are in Flockbook for the Herdr app. Flockbook for Mac stays at
> [v0.8.0](https://github.com/minchenlee/flockbook/releases/tag/v0.8.0): download it there. An installed Mac app
> keeps working and does not offer an update. To get v0.9.0, install or update the Herdr app mod (see Installation below).

### ✨ New

- Herdr app: the Overview grouped by status shows Done and Resting as two sections.
- Herdr app: drag a tab in the top bar to change the tab order. A line shows where it goes; dragging out of the bar cancels.
- Herdr app: drag a workspace in the sidebar up or down to change the workspace order. A line shows where it goes; dragging out of the list cancels.
- Herdr app mod: Flockbook settings in a dialog over the window, like Herdr's own Settings (check for updates, status row, helper on other machines), a quiet line when a newer Flockbook is out, and the install upgrades an older, unchanged Flockbook (a gallery copy) in place. *(preview)*

### 🐛 Bug Fixes

- Herdr app mod: ⌘V in the reply box attaches copied files and images. A file copied in Finder is attached instead of its name typed; a screenshot or a browser's Copy Image (also TIFF only) is attached as a PNG. Text still pastes as text, also from Excel, Numbers or Word.
- Herdr app mod: Enter in the middle of the reply sends it without a line break at the cursor. Before, that line break went out, and came back with the text after a failed send.
- Herdr app mod: Shift+Enter in the reply box starts a new line at the cursor. Before, it sent the reply. Enter still sends.
- Herdr app mod: the `flockbook` dark theme uses the same dark gray background colors as `flockbook mac` (before: black), and keeps its black-and-white accents. Dim text is a little lighter, so it stays as readable as before.
- Herdr app mod: a chat reply in Chinese or Japanese, or with inline code, no longer loses its last line under the time row, and a long pasted message no longer leaves a big empty space under it. Row heights now use the size the text is drawn at (16 px, 26 px lines), keep whole words and code together, and join lines that Markdown joins.
- Herdr app mod: on Herdr 0.1.13 you can select and copy text in the chat again. Before, a drag in a reply selected nothing.

### ⚙️ Changes

- Releases ship the Herdr app mod only. The Flockbook for Mac download links go to v0.8.0, the last Mac build.
