## What's New in v0.12.0

The "/" command list comes to every agent's chat, in the Herdr app mod and in Flockbook for Mac, with guards that keep a message from being sent into the wrong place. The Herdr app mod also gets a text size for the chat, and replies that were cut off at the bottom now show whole.

### ✨ New

- Herdr app mod: type "/" in the reply box to see the agent's commands, in Claude Code, Codex, pi and Antigravity CLI (agy) chats: your own commands, skills and plugins, pi's prompt templates and `/skill:` commands, agy's skills, and the common built-ins. ↑ ↓ or the wheel move through them 8 at a time ("4–11 of 20"), Tab or Enter completes the name, Esc closes. After `/model ` the list offers each agent's real models with their names (Claude Code's full ids such as `claude-opus-5-5` "Opus 5.5", Codex's models, pi's `provider/model` for the providers it has a key for, and agy's); type any part of a name ("sonnet", "flash") to find one. Needs the Flockbook helper of this release.
- Herdr app mod: Settings → General → Chat → Text size sets the chat's messages, code boxes and tables to Small (14 px), Default (16 px) or Large (18 px), without zooming the rest of Herdr. ⌥⌘- and ⌥⌘= step through them and ⌥⌘0 resets. Row heights follow the size.
- Herdr app mod: right-click a message in the chat and choose "Copy message" to copy its whole text as Markdown. It works when selecting text and ⌘C copy nothing (a drag across a code box, or a reply that is still being written).
- Flockbook for Mac: the same "/" list in the reply box of a Claude Code, Codex, pi or agy chat: ↑ ↓ or the wheel, Tab, Enter or a click completes the name, Esc closes; after `/model `, `/effort ` or `/thinking ` it offers the values with their names.
- Flockbook for Mac: right-click a message in the chat (yours or the agent's) and choose "Copy Message" to copy its whole text as Markdown, with nothing selected. On a code block it comes after "Copy Code".

### 🐛 Bug Fixes

- Herdr app mod, Flockbook for Mac and the phone page: a message is not sent when the agent's own input box in the terminal already has text in it (Claude Code, Codex, pi, agy and Grok Build). Before, the message was added after that text: a "/" left in the box made "/status" into "//status", which the agent took as a prompt. Now the chat says to clear the box in the terminal first and keeps your text.
- Herdr app mod, Flockbook for Mac and the phone page: a "/" command that opens a menu or a screen in the terminal (`/model`, `/status`) is not sent alone. `/model` stays in the box with a note: add a value, like `/model sonnet`. Commands that need the terminal and take no value (`/status`, `/config`, `/permissions` …) are not in the "/" list.
- Herdr app mod, Flockbook for Mac and the phone page: a message to Codex is sent when its box is empty under Codex's newer footer (model · folder · thread title, with no "% left"). That status line was read as text in the box, so every send stopped with "The agent's box has text in it".
- Herdr app mod: a Claude Code chat started with its own `CLAUDE_CONFIG_DIR` (for example a second account in `~/.claude-work`) shows its conversation. The helper looked for Claude's pid file and log only under `~/.claude`, and showed "No conversation yet".
- Herdr app mod: these replies show whole; before, the bottom of the message was cut off:
  - lines that end in two spaces or a backslash (Markdown hard breaks, as in Codex's short reports);
  - a table whose narrow column starts with long `code` (a tool name that breaks after its hyphen);
  - a message you sent with pictures (its "2 images" line was not counted);
  - a code block fenced with `~~~`, or with more words after its language (`` ```js title=a.js ``), which also drew the rest of the message as code.

### ⚙️ Changes

- Herdr app mod: the tab bar and the status tags above the reply box no longer draw a thick scrollbar over themselves. They still scroll sideways when they do not fit (trackpad, or the wheel).
- Herdr app mod: the "working" spinner turns more smoothly: a short arc over a faint ring, one turn in 0.9 s, like Herdr's own.
- Flockbook for Mac: the same spinner everywhere. The working mark of an agent keeps its blue; the places that wait (loading a conversation, earlier messages, a running tool, a queue pull, a question being sent, a machine test) show it in gray in place of the system spinner.
